## Вычислитель отличий

Вычислитель отличий - программа для сравнения двух конфигурационных файлов. Результат сравнения файлов может выводиться в разных форматах.

### Возможности утилиты:

* Поддержка разных входных форматов: yaml, json
* Генерация отчета в виде plain text, stylish и json

### Установка:

```
make install
npm link
```
